VoxelPort for Android runs a real [Paper](https://papermc.io) server **on the phone** and puts it online
through the [VoxelPort relay](https://github.com/VOXELPORT/relay). Your friends paste an address into
**Multiplayer → Add Server** and join with normal Minecraft: Java Edition. Bedrock players can join the same
server too.

## ⚡ From download to playing in five steps

| | |
|:-:|---|
| **1** | **Install** the app from [voxelport.in](https://voxelport.in/dl/voxelport-android.apk). It is a direct APK (about 55 MB), so Android asks you to allow installs from your browser once. |
| **2** | **Sign in with Discord** once. You join the VoxelPort Discord server, and VoxelPort never sees your Discord password or email. |
| **3** | Tick the Minecraft EULA, pick how much RAM to give the server, and tap **Install**. Java is already inside the app. The server download is about 135 MB, so use Wi-Fi. |
| **4** | Tap **Start**, wait for `Done!` in the console, then tap **Make Public**. |
| **5** | Share the address it shows, like `play.voxelport.in:26137`. Friends add it in Minecraft. Done. |

> **Heads up:** Android may say the app "may be harmful" or that Play Protect does not know it. That is because it
> is not on the Play Store. Tap **More details → Install anyway**. The whole app is open source, right here.

## ✨ What you get

- 🌍 **No port forwarding, even on Jio, Airtel or mobile data.** The phone dials out to the relay, so your router and home IP stay private.
- 🧱 **A real Paper server**, with live console, a RAM slider and a performance profile (Low / Balanced / High) picked from your phone's RAM and cores. Fabric is available too, for mods.
- 📱 **Bedrock players too:** one switch adds Geyser and Floodgate, so phone, console and Windows players join the same server.
- 🏷️ **A custom address**, like `yourname.voxelport.in`, for supporters. Everyone else gets `play.voxelport.in:<port>`.
- 🇮🇳🇪🇺 **Two relay regions:** the app measures India and Europe and picks the closer one.
- 🧩 **Plugins and mods in one tap:** browse [Modrinth](https://modrinth.com) from the app, install with the libraries they need, and every download is checked against Modrinth's checksum.
- 📂 **File manager and settings editor:** browse the server folder, import `.jar` files from the phone, and edit `server.properties` as a form.
- 💾 **World backups:** automatic backups while the server runs (only when the world changed) and a last one when you stop it, with one-tap restore.
- 📊 **Mobile-data meter:** set a daily limit (Wi-Fi only, 250 MB, 500 MB, 1 GB, 2 GB or none) and turn on **Data saver**, because a server on a phone can use a lot.
- 🔋 **Keep it running with the screen off:** step-by-step help for Samsung, Xiaomi, Oppo, Vivo, Huawei and other phones, which are aggressive about killing background apps.
- 🔁 **Address backup:** lock your address with a passphrase and save it to your Discord account, then restore it on a new phone or in the [desktop app](https://github.com/VOXELPORT/VoxelPort-App). VoxelPort cannot read the backup.
- 🗑️ **Delete server:** remove a server's world, plugins and settings from the phone when you are done. Your backups and address are kept.
- 📣 **Relay announcements:** if the relay is about to restart, you see it in the app and your players see it in the game chat.
- 📋 **Share an invite:** a ready message with the address and Bedrock instructions.
- 🇮🇳 **Hinglish interface:** switch the whole app to Hinglish (Hindi in the English alphabet).
- 🔓 **Cracked players:** an optional switch that states its risks before it turns anything on, with one-tap login protection.
- 🔄 **Updates itself** from voxelport.in, because the app is sideloaded and there is no store to do it.

## ❓ FAQ

<details>
<summary><b>Will my phone handle it?</b></summary>

You need an **arm64 phone on Android 8.0 or newer** and about **1.2 GB of free storage**. With 4 GB of RAM it hosts
a few friends on the Low profile, and 8 GB or more runs comfortably. Hosting is heavy: keep the phone on Wi-Fi and
charging if you can.
</details>

<details>
<summary><b>Do my friends need to install anything?</b></summary>

No. They use normal Minecraft: Java Edition and the address the app shows you. Bedrock players need no extra app
either. They use the same address.
</details>

<details>
<summary><b>Why do I sign in with Discord?</b></summary>

To host publicly you sign in with Discord and join the [VoxelPort Discord server](https://discord.gg/JAUfmey2fP), which is
where updates, help and giveaways live. VoxelPort only receives your permanent Discord ID, your display name and whether you
are in the server. It never sees your email, password or an access token. Friends who just play never sign in.
</details>

<details>
<summary><b>Is it free?</b></summary>

Yes. The app and the relay are free and open source (MIT), with no ads and no player limits. If it helped you,
you can [support it](https://voxelport.in/support). Tips are voluntary and earn a Supporter rank as a thank-you.
</details>

<details>
<summary><b>The server stopped when I locked the phone.</b></summary>

Some phone makers close background apps to save battery. Open the app's **keep it running** card for your maker's
steps, allow the battery-optimisation prompt, and lock VoxelPort in the recent apps list.
</details>

<details>
<summary><b>How do I move to a new phone?</b></summary>

Use **Address backup** to save your address to your Discord account, then sign in on the new phone and restore it.
The same backup works in the desktop app. If you also want your world, make a world backup first and keep a copy of
it somewhere safe, because uninstalling the app deletes the server files stored inside it.
</details>

<details>
<summary><b>I am on an older build. How do I update?</b></summary>

Builds up to 13 were signed with a key that was lost, so Android cannot update them to build 14 or later. They need a
one-time reinstall: copy your address code first (**Back up or restore your address**), uninstall, install the new
build, then restore the code. Uninstalling deletes the server files stored inside the app, so copy out anything you
want to keep. Builds from 14 on update in place.
</details>

## 🛠️ How it works

The phone is an arm64 Linux machine, so the app ships an OpenJDK 25 runtime and starts it inside its own
`:jvm` process, calling the JVM's launcher through JNI (`app/src/main/cpp/launcher.c`). The tunnel to the
relay is the same Go code the desktop app and the command-line client use, compiled for Android with
`gomobile` (VoxelPort's Go `cli` project, which is not public yet). The UI is Kotlin and Jetpack Compose.

| Where                                    | What                                                              |
| ---------------------------------------- | ----------------------------------------------------------------- |
| `app/src/main/java/.../MainActivity.kt`  | The screens and the whole host flow                               |
| `ServerService.kt`, `TunnelService.kt`   | Foreground services: the Java server and the relay tunnel         |
| `Setup.kt`, `Jvm.kt`                     | Unpacking Java, downloading Paper, building the launch command    |
| `Tuning.kt`, `YamlEdit.kt`               | The performance profiles and the config edits they make           |
| `DataLogic.kt`, `DataMeter.kt`           | The mobile-data meter and limits                                  |
| `AppAccount.kt`, `GateLogic.kt`, `AccountLogic.kt` | Discord sign-in and the rule for who may host publicly  |
| `IdentityBackup.kt`, `BackupUi.kt`       | The passphrase-locked address backup (same format as the desktop app) |
| `Backups.kt`, `BackupRunner.kt`          | World backups                                                     |
| `ServerDelete.kt`                        | Deleting the server safely                                        |
| `UpdateLogic.kt`, `Updater.kt`           | The self-updater                                                  |
| `app/src/main/cpp/`                      | The JNI launcher that starts the JVM                              |
| `tools/publish-android.sh`               | How the official build is published (you do not need it)          |

The pure logic (tuning, YAML edits, the data meter, update checks, the Discord gate, the address backup crypto) has
JUnit tests in `app/src/test`. The backup test opens a blob made by the desktop app's code, so the two stay compatible.

## 🍴 Forking

If you ship your own build, change `applicationId`, the update feed (`MANIFEST_URL` in
`UpdateLogic.kt`) and the support links, so your users are not offered VoxelPort's updates and your
build is clearly yours. The VoxelPort name and logo belong to VoxelPort: please do not use them for an
unofficial fork.
